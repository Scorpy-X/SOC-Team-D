# Deterministic Explanation Reference

This file lists the current deterministic explanation strings and templates used
by the advisor path when the optional report LLM is disabled.

Use it to review exactly what the system can say without involving OpenAI.

Important boundary:

- scoring, liquidity checks, risk checks, constraints, optimizer output, chat
  summary structure, and audit reporting are deterministic
- the optional OpenAI path only rewrites three user-report prose blocks
- if `ADVISOR_REPORT_USE_LLM` is off, the whole explanation surface below is
  the active wording source

## Main Files

- `backend/soc_advisor/decision_explanations.py`
- `backend/soc_advisor/chat_formatting.py`
- `backend/soc_advisor/risk_reality.py`
- `backend/soc_advisor/report_llm.py`
- `config/portfolio/v3.json`

## Profile Descriptions

These are the active profile description strings from
`config/portfolio/v3.json`.

- `Very Conservative`
  `Capital-preservation profile with the strongest cash and fixed-income anchor and only a limited growth allowance.`
- `Conservative`
  `Stability-first profile with fixed income as the main anchor and a modest allowance for growth assets.`
- `Balanced`
  `Middle-ground profile that balances a stabilizing fixed-income sleeve with meaningful growth exposure.`
- `Growth`
  `Growth-oriented profile where equity is the main allocation while fixed income and cash remain available for balance.`
- `Aggressive`
  `Highest-growth profile, allowing equity to dominate while preserving only small optional stability sleeves.`

## Profile Explanation Templates

These lines are generated by `build_profile_explanation_lines(...)`.

Fallback when no `DecisionTrace` exists:

- `The report uses the {profile_label} investor profile.`

Manual override path when review kept the same profile the questionnaire had
already estimated:

- `The questionnaire estimated {draft_profile_label}, and advisor review kept that profile before the liquidity check.`

Manual override path when review changed the questionnaire profile:

- `Advisor review used the {manual_override_label} profile instead of the questionnaire draft profile, which was {draft_profile_label}.`

Scored questionnaire path:

- `{final_profile_label} means ...`
- `Risk capacity: {low|medium|high}. ...`
- `Risk tolerance: {low|medium|high}. ...`
- `Decision: the system selected {final_profile_label} because ...`
- `Technical note: capacity {capacity_score_percent}, tolerance {tolerance_score_percent}, displayed risk score {risk_score_10}.`

The exact profile meaning lines are:

- `Very Conservative means the portfolio is focused mainly on capital preservation and liquidity.`
- `Conservative means the portfolio prioritizes stability and income, with limited growth exposure.`
- `Balanced means the portfolio keeps a mix of stability and growth exposure.`
- `Growth means the portfolio targets higher long-term growth and accepts more short-term movement.`
- `Aggressive means the portfolio prioritizes long-term growth and assumes the investor can tolerate large short-term losses.`

Cap-rule line, when applicable:

- `A cap rule limited the maximum profile because the market-drop answer showed the investor may fully exit after a severe decline.`

Liquidity line:

- `Liquidity need: {low|medium|high}. The liquidity check adjusted the profile from {selected_profile_label} to {effective_profile_label} so the portfolio could support the required Cash reserve.`
- `Liquidity need: {low|medium|high}. The selected profile could support the required Cash reserve without adjustment.`

Review-only fallback when scoring trace is absent:

- `The report uses the {profile_label} investor profile selected during review.`

## Liquidity Explanation Templates

These lines are generated by `build_liquidity_explanation_lines(...)`.

Always shown when a liquidity policy trace exists:

- `Required liquidity was calculated as expected major withdrawals plus essential monthly expenses multiplied by the selected emergency reserve.`
- `The required Cash reserve was {required_liquidity_amount}, or {liquidity_floor_percent} of the portfolio value entered.`

Shown only when liquidity changed the profile:

- `The original {selected_profile_label} profile could not support that Cash level, so the compatible profile used was {effective_profile_label}.`

## Risk Reality Check Prompt

This prompt is generated by `render_risk_reality_prompt(...)`.

Header and explanation:

- `Risk reality check for {profile_label}`
- `This profile has an estimated annual volatility of {annual_volatility_percent}.`
- `A rough severe-volatility illustration is {stress_percent}{optional_stress_amount}.`
- `This is not a prediction, maximum loss, or formal risk model. It is a simple stress illustration based on two times the portfolio's estimated annual volatility.`
- `Type yes to generate the report.`

## Final Chat Summary Wording

The final chat summary is built by `render_profile_summary(...)`.

Stable section headers:

- `Draft portfolio snapshot: {profile_label}`
- `Investor type: {profile_label}`
- `Recommendation basis: {basis_label}`
- `Why this profile`
- `Portfolio mix`
- `Investments selected`
- `Key estimates`
- `Important caveats`

Conditional lines:

- `Risk score: {risk_score_10}`
- `Portfolio value used for display: {portfolio_value_label}`
- `I attached the detailed portfolio report below. Use the report card to see a quick summary first, then open or download the full file.`

Deterministic caveat lines:

- `This result uses the profile selected during review.`
- `This result uses a profile adjusted after the liquidity check.`
- `This result uses the profile calculated from the questionnaire.`
- `Dollar figures are estimates based on the portfolio value you entered; they do not change the allocation.`
- `Expected returns are estimates, not guarantees.`
- `Type /restart to run the questionnaire again.`

## Deterministic User-Report Prose

These three blocks come from `build_deterministic_report_prose(...)` and are
the exact fallback used when the report LLM is off or fails.

Executive summary:

- `This draft demo report shows a {profile_label} portfolio. It summarizes the suggested investment mix, key portfolio estimates, and the investments included in this draft portfolio.`

Allocation explanation:

- `The current mix is {class_mix}. The estimated yearly return is {expected_return} and the expected yearly movement is {volatility}. Currency exposure is {currency_mix}.`

Limitation note:

- `This is a draft demo report. The liquidity answers are used for a Cash reserve check, but the full suitability model is still under development. Expected returns are estimates rather than guarantees.`

## What Is Parameterized Versus Fixed

Fixed text means the wording is fully controlled in code. Parameterized text
means a small set of values is inserted into a fixed template.

Parameterized values include:

- profile labels
- risk-capacity and risk-tolerance percentages
- 1-to-10 risk score label
- liquidity amount and liquidity-floor percentage
- volatility and stress percentages
- portfolio-value-based dollar estimates
- portfolio mix and currency mix summaries

## What This Lets You Review

If you keep the report LLM off, this file is the reviewable explanation set for:

- why the system used a profile
- whether liquidity changed it
- how the pre-report stress illustration is phrased
- the main user-facing report summary wording
- the main chat snapshot wording

If you later enable the report LLM, this file still remains the deterministic
fallback and the bounded baseline the LLM is supposed to improve on, not replace
logically.
